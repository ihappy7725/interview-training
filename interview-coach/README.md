# 🎙️ InterviewLab — AI 면접 연습기

카메라와 마이크로 실제 면접처럼 답변하면 **MediaPipe**가 시선·자세를 실시간으로 코칭하고,
**OpenAI**가 답변 내용을 평가해 점수와 상세 리포트를 만들어 주는 Streamlit 앱입니다.

```
질문 준비(실제 기출 수집 + AI 예상 질문) → 모의 면접(카메라·마이크) → 즉시 피드백 → 리포트 → 성장 기록
```

---

## 1. 실행 방법

### 1) 준비물
- Python **3.10 이상** (3.13에서 테스트함)
- 웹캠·마이크가 있는 PC, Chrome 또는 Edge 브라우저
- OpenAI API 키 ([platform.openai.com/api-keys](https://platform.openai.com/api-keys)에서 발급, 사용량만큼 과금)

### 2) 설치

**Windows (PowerShell)**
```powershell
cd interview-coach
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**macOS / Linux**
```bash
cd interview-coach
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

> PowerShell에서 `Activate.ps1` 실행이 막히면 한 번만 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`를 실행하세요.

### 3) `.env`에 API 키 넣기
프로젝트 폴더에 `.env` 파일이 이미 있습니다. 첫 줄을 본인 키로 바꾸세요.

```env
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxx
```

`.env`가 없다면 `.env.example`을 복사해서 만드세요 (`cp .env.example .env`, Windows는 `copy .env.example .env`).
`.env`는 `.gitignore`에 포함되어 있어 GitHub에 올라가지 않습니다.

### 4) 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`이 열립니다.

- **처음 ‘모의 면접’ 화면에 들어가면** MediaPipe 얼굴 모델(`face_landmarker.task`, 약 4MB)을 자동으로 내려받아 `models/`에 저장합니다.
- `📷 카메라 켜기`를 누르고 브라우저의 카메라 권한을 허용하세요. 녹음할 때는 마이크 권한도 허용합니다.

#### 모델 수동 다운로드 (자동 다운로드가 실패할 때)
아래 주소의 파일을 받아 `models/face_landmarker.task` 이름으로 저장한 뒤 앱을 재시작하세요.
```
https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task
```

## 2. 사용 흐름

1. **📝 질문 준비**
   - 회사명·직무·면접 유형·채용공고(JD)·이력서 핵심을 입력합니다.
   - `웹에서 기출 질문 찾기`: 공개된 면접 후기·채용 페이지·기사를 웹 검색해 실제 질문과 출처 링크를 보여줍니다.
   - 로그인해야 보이는 후기(잡플래닛 상세 등)는 앱이 읽을 수 없으니, 직접 보고 `직접 수집한 기출 질문` 칸에 붙여넣으세요.
   - `예상 질문 생성`: 지원 정보와 기출 질문을 참고해 의도·팁이 붙은 예상 질문을 만듭니다.
   - 표에서 질문을 고치거나 추가·삭제한 뒤 `이 질문으로 모의 면접 시작`.
2. **🎥 모의 면접**
   - `🔊 질문 듣기`로 면접관처럼 질문을 읽어줍니다.
   - `▶ 답변 시작`을 누르면 타이머가 돌고 시선 지표가 0부터 다시 측정됩니다. 그다음 🎙 녹음 버튼을 눌러 답하고, 끝나면 정지하세요.
   - 정지하면 자동으로 분석됩니다. 즉시 피드백이 글자 단위로 먼저 나오고, 이어서 점수와 상세 평가가 표시됩니다.
   - `↪ 꼬리질문 연습하기` / `🔁 같은 질문 다시 답하기`로 이어서 연습합니다. 재시도하면 이전 점수 대비 변화가 표시됩니다.
3. **📊 리포트**: 종합·내용·전달력·비언어 점수, 역량 레이더, 질문별 상세, AI 종합 진단. `.md`로 내려받거나 `성장 기록에 저장`.
4. **📈 성장 기록**: 저장한 세션의 점수 추이를 그래프로 봅니다 (`data/history.json`에 로컬 저장).

## 3. 기능과 구현 방식

| # | 요청 기능 | 구현 |
|---|---|---|
| 1 | 카메라 실시간 연습 (MediaPipe 얼굴 인식) | `streamlit-webrtc` + MediaPipe **Face Landmarker**. 얼굴 인식률, 정면 응시, 머리 각도, 눈 깜빡임, 미소, 머리 움직임을 프레임마다 계산하고 영상 위와 ‘실시간 코칭’ 패널에 1초 간격으로 표시 |
| 2 | GPT 기반 실시간 피드백 | 녹음을 멈추는 즉시 GPT 피드백을 **스트리밍**으로 출력 (말하는 도중이 아니라 답변 1개가 끝난 직후) |
| 3 | 말하기 속도·논리성·구체성 평가 | 속도는 전사 텍스트와 녹음 길이로 계산(음절/분, words/min, 字/分). 논리성·구체성·질문 적합성·구조(STAR)는 GPT 루브릭 채점 |
| 4 | 점수 + 상세 리포트 | 종합/내용/전달력/비언어 점수, 레이더·막대 차트, 질문별 상세, AI 종합 진단, Markdown 다운로드 |
| 5 | 마이크로 실제 면접처럼 | `st.audio_input` 녹음 → OpenAI 음성 인식(`gpt-transcribe`) |
| 6 | “음”, “어”, “um”, “uh” 습관어 체크 | 간투사(음·어·아, um·uh, 嗯·呃)는 점수에 반영. ‘이제·약간·like·那个’처럼 의미가 있을 수도 있는 말은 **습관 표현 후보**로만 따로 표시 |
| 7 | 목소리 톤·자신감 분석 | `librosa`로 억양 변화(반음), 말끝 음량 처짐, 2초 이상 멈춤, 첫 마디까지 걸린 시간, 음량 편차를 계산해 ‘음성 자신감(추정)’ 점수와 근거 제시 |
| 8 | 맞춤형 질문 생성 | 회사·직무 입력 → 웹 검색으로 실제 기출 수집(출처 링크 + 인용 확인 표시) → AI 예상 질문 생성 |
| 9 | `.env`로 OpenAI API 키 관리 | `python-dotenv`로 로드. 모델명도 `.env`에서 변경 가능 |
| 10 | Python | 전체 Python |
| 11 | Streamlit | 4개 화면, 레퍼런스(화상회의 대시보드) 스타일의 화이트 카드 + 블루 포인트 테마 |
| 12 | README 실행 방법 | 이 문서 |

### 추가로 넣은 기능 (실용성 기준으로 선별)
| 기능 | 이유 |
|---|---|
| **STAR 체크리스트** | 경험 질문에서 상황·과제·행동·결과 중 빠진 요소를 바로 보여줌 |
| **꼬리질문 연습** | 실제 면접은 첫 답변보다 꼬리질문에서 갈리는 경우가 많음. 내 답변을 바탕으로 생성 |
| **답변 시간 타이머·제한** | 1분 자기소개, 90초 답변처럼 시간 감각 훈련. 초과 시 표시 |
| **개선 답안 예시 (사실 날조 금지)** | 내가 말하지 않은 수치·경험은 `[구체적 수치]`처럼 빈칸으로 남겨 자소서와 어긋나지 않게 함 |
| **같은 질문 재도전 + 점수 변화** | 반복 연습 효과를 바로 확인 |
| **영어·중국어 면접 모드** | 사이드바에서 언어 선택 → 질문 생성·음성 인식·속도 단위·습관어 사전이 함께 바뀜 |
| **질문 음성 읽기** | 브라우저 내장 음성(Web Speech API) 사용 → 추가 API 비용 없음 |
| **성장 기록** | 세션별 점수 추이를 저장해 연습 효과를 추적 |
| **출처 확인 표시** | 웹 검색으로 모은 기출 질문이 실제 검색 인용 URL과 일치하는지 표시해 출처 없는 질문을 구분 |

### 이번에는 넣지 않았지만 다음 단계로 추천
- **이력서 PDF 업로드 → 자동 요약**: 지금은 텍스트 붙여넣기 방식. `pypdf`로 쉽게 확장 가능
- **음성 대화형 면접관**: OpenAI Realtime API로 면접관이 말로 묻고 바로 꼬리질문. 몰입감은 크지만 비용·구현 난이도가 높음
- **답변 영상 녹화·다시보기**: 자기 모습 확인에 유용하지만 영상 파일 저장에 따른 개인정보 관리가 필요

## 4. 점수 산정 방식과 한계

```
종합 = 내용 55% + 전달력 25% + 비언어 20%   (카메라를 끄면 내용·전달력만으로 재계산)
내용   = (논리성 + 구체성 + 질문 적합성 + 구조) / 4         ← GPT 루브릭 채점
전달력 = (말하기 속도 + 습관어 절제 + 음성 자신감) / 3      ← 음성 신호·전사 텍스트
비언어 = 정면 응시 50% + 얼굴 인식률 20% + 머리 안정성 15% + 표정 15%  ← MediaPipe
```

꼭 알아둘 점:
- **점수는 연습용 지표입니다.** 가중치와 기준값은 일반적인 면접 코칭 관점을 반영한 휴리스틱이며, 실제 합격 여부와의 상관관계로 검증된 값이 아닙니다. 같은 답변도 GPT 채점은 몇 점씩 달라질 수 있습니다.
- **말하기 속도 참고 범위**(한국어 250–350 음절/분, 영어 120–160 wpm, 중국어 180–260 字/分)는 표준이 아니라 기본값입니다. `core/config.py`의 `pace_range`에서 조정하세요.
- **시선은 ‘추정’입니다.** 머리 회전각과 눈동자 방향 계수로 판단하므로 안경·조명·카메라 위치에 따라 오차가 있습니다. 노트북 카메라처럼 화면 위에 카메라가 있으면 화면을 볼 때 약간 아래를 보게 되는데, 이 정도는 허용하도록 설정했습니다(`core/vision.py` 상단 기준값).
- **음량 절대값은 신뢰도가 낮습니다.** 브라우저가 마이크 음량을 자동으로 조절하는 경우가 많아, 억양 변화·말끝 처짐·침묵 같은 상대 지표 위주로 봅니다.
- 음성 인식 모델이 간투사를 생략할 수 있어, 간투사가 포함된 예시 문장을 전사 프롬프트로 넣어 최대한 보존하도록 했습니다. 그래도 실제보다 적게 잡힐 수 있습니다.

## 5. 비용과 개인정보

- **카메라 영상은 내 PC에서만 분석**되며 외부로 전송되지 않습니다.
- **녹음한 음성과 답변 텍스트는 OpenAI API로 전송**됩니다. 민감한 개인정보는 답변에 넣지 않는 것을 권장합니다.
- 답변 1개당 API 호출: 음성 인식 1회 + 즉시 피드백 1회 + 상세 평가 1회. 기출 질문 수집은 웹 검색 도구 비용이 별도로 붙습니다. 정확한 요금은 [OpenAI 가격 페이지](https://openai.com/api/pricing/)에서 확인하세요.

## 6. 설정 (`.env`)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (필수) | API 키 |
| `OPENAI_CHAT_MODEL` | `gpt-5.4-mini` | 질문 생성·피드백·평가 |
| `OPENAI_SEARCH_MODEL` | CHAT_MODEL과 동일 | 기출 질문 웹 검색 (Responses API `web_search` 도구) |
| `OPENAI_TRANSCRIBE_MODEL` | `gpt-transcribe` | 음성 → 텍스트 |
| `OPENAI_REASONING_EFFORT` | (비움) | `low`로 두면 응답이 빨라짐. 지원하지 않는 모델에서는 비워두세요 |

> 모델 정보는 2026년 11월 OpenAI 문서 기준입니다. OpenAI 문서에 따르면 `whisper-1`, `gpt-4o-transcribe` 등은 2027-02-26 종료 예정이라 기본값을 `gpt-transcribe`로 두었고,
> OpenAI 음성합성(TTS) 모델도 2027-01-06 종료 예정이라 질문 읽기는 브라우저 내장 음성을 사용합니다. 모델이 바뀌면 코드 수정 없이 `.env`만 고치면 됩니다.

├─ .env / .env.example

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 사이드바에 ‘API 키 없음’ | `.env`의 `OPENAI_API_KEY` 확인 후 앱 재시작 (`Ctrl+C` → `streamlit run app.py`) |
| 카메라가 안 켜짐 | 주소가 `localhost`인지 확인 (카메라·마이크는 `localhost` 또는 HTTPS에서만 동작). 다른 앱(Zoom 등)이 카메라를 쓰고 있지 않은지 확인 |
| 얼굴 인식 모델 다운로드 실패 | 위의 ‘모델 수동 다운로드’ 참고. 회사·학교 네트워크에서 막히는 경우가 있음 |
| `pip install mediapipe` 실패 | Python 버전 확인 (`python --version`). 너무 최신이거나 32비트 Python이면 설치 파일이 없을 수 있음 → 3.11/3.12로 가상환경 재생성 |
| 분석이 느림 | `.env`에 `OPENAI_REASONING_EFFORT=low` 추가 |
| 다른 PC나 클라우드에 배포했더니 영상이 안 나옴 | WebRTC 연결에 TURN 서버가 필요할 수 있음 (`app.py`의 `rtc_configuration`에 추가). 로컬 실행은 문제없음 |
| 습관어가 실제보다 적게 잡힘 | 음성 인식 특성상 일부 생략될 수 있음. 전사 텍스트를 보고 판단 |
